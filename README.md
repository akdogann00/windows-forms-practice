## 🚀 Getting Started

### Prerequisites

- Windows
- Visual Studio with the appropriate .NET desktop development components
- The .NET runtime or .NET Framework required by the selected project

### Run a Project

1. Open the repository on GitHub.
2. Select **Code → Download ZIP** and extract the downloaded archive.
3. Open the folder of the project you want to run.
4. Open its `.sln` solution file, if available, or its `.csproj` project file in Visual Studio.
5. Restore dependencies if required.
6. Build and run the project.

Each project is maintained in its own folder. Project files and framework requirements may differ between exercises.

## 🔐 Featured Project: Simple Login

The `15.simple.login.project` folder contains a beginner-level login form exercise.

The project is part of my practice with Windows Forms and interactive desktop application development.
