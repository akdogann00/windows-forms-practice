# Windows Forms Practice & C# Projects

This repository contains desktop application examples, UI layout practices, and event-driven programming exercises developed with C# and Windows Forms as part of my coursework and personal practice.

## Contents
* Basic UI controls (Buttons, Labels, TextBoxes, ComboBoxes)
* Event handling and user input processing
* Basic arithmetic algorithms and form-based calculators
* Multi-form navigation and data transfer between forms
* Object-Oriented Programming (OOP) practice in GUI applications

## Requirements & How to Run
* **Framework:** .NET / C#
* **IDE:** Visual Studio (with .NET desktop development workload)

To run any project locally:
